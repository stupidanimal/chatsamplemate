# AI Companion - 情感AI伴侣

> **不是普通桌宠，是有灵魂的AI伙伴**

一个能通过对话表达真实情绪的AI伴侣。不同于传统桌宠的简单点击互动，AI Companion 会根据对话内容自动感知情绪并切换表情——开心时笑、难过时哭、思考时沉思、害羞时脸红。

## 🎯 为什么不一样？

| 传统桌宠 | AI Companion |
|---------|--------------|
| 点击触发固定反应 | AI理解对话，自然表达情绪 |
| 预设几个动作 | 13种情绪，无限对话 |
| 机械重复 | 每次对话都不同 |
| 无记忆 | 有上下文，记得你说过什么 |

## ✨ 核心特点

- 🎭 **AI驱动情绪** - AI会在回复中自动标注情绪标签，程序实时切换表情
- 🖼️ **头像可替换** - 用户可以替换成自己喜欢的图片风格
- 💬 **深度对话** - 基于DeepSeek API，支持上下文记忆
- 🎨 **开源免费** - MIT协议，可自由修改和分发
- 🔌 **多模型支持** - 支持DeepSeek、OpenAI、Ollama等

## 📦 安装

```bash
# 克隆项目
git clone https://github.com/your-username/ai-companion.git
cd ai-companion

# 安装依赖
pip install -r requirements.txt
```

## 🚀 快速开始

1. 获取 DeepSeek API Key：https://platform.deepseek.com/

2. 运行程序：
```bash
python src/main.py
```

3. 在设置界面填入API Key，开始聊天！

## 🎭 情绪系统

AI会在回复中自动添加情绪标签，程序根据标签显示对应表情：

```
用户：今天考试没考好...
AI：[悲伤] 没关系的，下次一定会更好的！
     ↓
程序显示"悲伤"表情
```

支持的情绪：

| 情绪 | 标签 | 场景示例 |
|------|------|----------|
| 高兴 | `[高兴]` | 听到好消息、夸奖 |
| 生气 | `[生气]` | 听到不公平的事 |
| 悲伤 | `[悲伤]` | 听到难过的事 |
| 惊讶 | `[惊讶]` | 意外的消息 |
| 害羞 | `[害羞]` | 被夸奖、暧昧 |
| 思考 | `[思考]` | 复杂问题 |
| 说话 | `[说话]` | 普通对话 |
| 困惑 | `[困惑]` | 不理解的内容 |
| 得意 | `[得意]` | 完成任务 |
| 无聊 | `[无聊]` | 无话可说 |
| 兴奋 | `[兴奋]` | 期待的事 |
| 委屈 | `[委屈]` | 被误解 |

## 🖼️ 自定义头像

1. 准备13张对应情绪的图片（PNG格式，建议150x150像素）
2. 命名规则：
   ```
   assets/emotions/
   ├── default.png    # 默认
   ├── happy.png      # 高兴
   ├── angry.png      # 生气
   ├── sad.png        # 悲伤
   ├── surprised.png  # 惊讶
   ├── shy.png        # 害羞
   ├── thinking.png   # 思考
   ├── speaking.png   # 说话
   ├── confused.png   # 困惑
   ├── proud.png      # 得意
   ├── bored.png      # 无聊
   ├── excited.png    # 兴奋
   └── wronged.png    # 委屈
   ```
3. 或者在程序中点击"更换头像"选择自定义目录

## 🔧 配置

- **API Key**: DeepSeek/OpenAI API密钥
- **AI性格**: 自定义AI的性格描述（温柔、傲娇、高冷等）
- **头像目录**: 可以更换为任意包含情绪图片的文件夹
